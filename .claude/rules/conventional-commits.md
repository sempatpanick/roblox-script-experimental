# Conventional Commits

Git commit messages must use Conventional Commits. See `docs/style/commits.md`.

Format: `<type>(<optional-scope>): <description>`

Allowed types: `feat`, `fix`, `refactor`, `docs`, `style`, `chore`, `perf`, `revert`.

Example: `feat(mount-daun): add auto carry and auto accept carry`

Do not use titles like `Add Auto Carry to Mount Daun.` Commit only when the user asks.
