# Project context

This workspace is **sempatpanick**, a Roblox executor hub. The local folder name `cobalt` is not the product name.

Follow root `CLAUDE.md` and `docs/README.md`. Do not edit `Cobalt.luau`. New games go in `games/sempat/` and must be registered in both `sempatpanick.lua` and `sempatpanick_local.lua`. Dual-load modules with `require` then `HttpGet`.
